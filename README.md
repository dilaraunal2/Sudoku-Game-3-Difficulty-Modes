# Sudoku Game

A web-based Sudoku game with multiple difficulty levels and hint functionality.

## Features

- Three difficulty levels: Easy, Medium, and Hard
- Hint system with 3 hints per game
- Input validation (only numbers 1-9 allowed)
- Visual feedback for incorrect/correct answers
- Responsive design
- Green animation for completed puzzles

## How to Play

1. Select a difficulty level from the start screen
2. Fill in the empty cells with numbers from 1 to 9
3. Each row, column, and 3x3 box must contain all digits from 1 to 9 exactly once
4. Use the "Check" button to verify your solution
5. Use the "Hint" button if you need help (limited to 3 hints per game)
6. Click "New Game" to return to the difficulty selection screen

## Game Rules

- The Sudoku grid is 9x9, divided into nine 3x3 subgrids
- Some cells are pre-filled with numbers (shown in bold)
- Fill the empty cells so that each row, column, and 3x3 subgrid contains all digits from 1 to 9
- No number can repeat in any row, column, or 3x3 subgrid

## Difficulty Levels

- **Easy**: 30 empty cells
- **Medium**: 45 empty cells
- **Hard**: 60 empty cells

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run

Simply open the `index.html` file in a web browser.

## Browser Compatibility

Compatible with all modern browsers including Chrome, Firefox, Safari, and Edge.
